HOW TO ADD A STORY

Drop a new .txt file in this folder for each transcribed submission. The site
reads every .txt file here automatically — no code changes needed. Files that
don't match the format below are skipped.

Format (exact structure, blank line after the profile block):

Storyteller profile
Name: <first name or initial — use a fictitious name if needed>
Age Range: <e.g. Early 20s>
General Demeanor: <a sentence or two describing how they came across>

<Story Title>
<paragraph one, one line>
<paragraph two, one line>
<...>

Notes:
- The blank line between "General Demeanor" and the title is required.
- After the title, each line becomes its own paragraph — don't wrap a
  paragraph across multiple lines, keep it on one line.
- File name doesn't matter, but a short slug like
  "firstname-story-title.txt" keeps the folder readable.

See t-moving-to-new-york-at-fifteen.txt for a real example.
